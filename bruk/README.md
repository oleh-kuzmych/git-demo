## Що де лежить

```

  artifact/bruk_schemes.html   інтерактивна сторінка: характеристики, схеми, калькулятор

  textures/<схема>/            PBR-карти, безшовні
      *_BaseColor.jpg  (sRGB)
```

## Чому такі формати

* **PBR-текстури** (як на poliigon.com) — універсальний формат: працює в Blender, Archicad, Twinmotion, Lumion, Enscape, D5, 3ds Max/Corona/V-Ray, SketchUp, Unreal. Саме з них будується «сфера» матеріалу.
* **.blend** — готова сцена: матеріали вже зібрані, лишається перетягнути на об'єкт.
* **DXF** — відкривається в Archicad, AutoCAD, Revit, BricsCAD; кожен камінь — окрема замкнена полілінія на шарі свого формату, тож схему легко редагувати й рахувати.

## Blender (5.0+)

1. Відкрийте `blender/bruk_schemes.blend` у Blender 5.0 або новішому (файл збережено у 5.0; для старіших версій зберіть сцену скриптом `tools/build_blend.py`). Папку `bruk/` тримайте цілою — текстури підключені відносними шляхами.
2. Матеріали `Bruk_01_…` – `Bruk_10_…` позначені як Assets: Asset Browser → Current File → перетягніть на об'єкт.
3. Масштаб: у матеріалі 1 одиниця UV = 1 м. Для площини розміром 6×4 м розгорніть UV і відмасштабуйте до 6×4 (або в матеріалі замініть вихід `UV` вузла Texture Coordinate на `Object` — для плоских ділянок це найпростіше).
4. Рельєф швів: Cycles → Material → Settings → Displacement = *Displacement and Bump* + модифікатор Subdivision (Simple, 5–6 рівнів на рендер). В Eevee працюють нормалі.
5. Перерендерити сфери: `blender -b -P bruk/tools/build_blend.py -- --render --samples 128`.

## Archicad

**Матеріал (3D/рендер):** Options → Element Attributes → Surfaces → New.
* Texture: `*_BaseColor.jpg`, розмір текстури — ширина × висота з колонки «Тайл текстури» (напр. 1440 × 1440 мм).
* Renderer (Redshift/CineRender): Normal/Bump → `*_Normal.jpg`, Displacement → `*_Displacement.png` (висота 10 мм), Roughness → `*_Roughness.jpg`.
* Призначте поверхню перекриттю/Mesh/Shell мощення; початок і напрям текстури задайте командою Align 3D Texture → Set Origin.

**2D-план:** File → Interoperability → Merge… → `dxf/<схема>.dxf` (одиниці — мм). Шари `BRUK_*` стануть шарами Archicad. Щоб зробити штрихування: виділіть лінії одного модуля → Copy → Options → Element Attributes → Fills → New → Symbol Fill → Paste.

## Інші програми

* **Twinmotion / Lumion / Enscape / D5:** створіть матеріал, підставте карти за назвами, розмір тайла — з `textures.json`.
* **3ds Max (DirectX), Unreal:** інвертуйте зелений канал нормалі (Flip Green / Y−).
* **SketchUp:** Materials → Create → `*_BaseColor.jpg`, розмір — з таблиці; решта карт — у V-Ray/Enscape.

## Перегенерувати

```bash
pip install numpy pillow scipy ezdxf shapely
python3 bruk/tools/build_vectors.py              # SVG, DXF, schemes.json
python3 bruk/tools/build_textures.py --res 4096  # текстури 4K (за замовчуванням 2048)
blender -b -P bruk/tools/build_blend.py -- --render
python3 bruk/tools/build_artifact.py             # сторінка з прев'ю
```

Параметри рельєфу (шов 4 мм, фаска 6 мм, кольори) — на початку `tools/build_textures.py`; нові схеми додаються у `SCHEMES` в `tools/schemes.py`.
