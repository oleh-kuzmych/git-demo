# Плита тротуарна 400×200×60 — 10 схем викладки

Розміри — з технічного завдання на форму ВР-2664 (03.2021), колір — з фото викладки.

| Параметр | Значення |
|---|---|
| Номінальний розмір | 400 × 200 × 60 мм |
| Внутрішній розмір форми | 398 × 198 мм |
| Радіус кутів у плані | R5 |
| Фаска | ≈5 мм (за кресленням) |
| Плит на 1 м² | 12,5 шт |
| Вага 1 м² / 1 плити | ≈138 кг / ≈11 кг (розрахунок для бетону 2300 кг/м³) |
| Колір | колормікс: графіт, коричнево-сірий, бежевий |

Ціну та кількість м² на піддоні в документах не вказано — уточніть у виробника (у калькуляторі на сторінці є поля для них).

## Схеми

«Поздовжніх / поперечних» — частка плит, покладених довгою стороною вздовж / впоперек осі X креслення. «Підрізка» — скільки плит розрізається на квадратній ділянці 2,4×2,4 м.

| № | Схема | Поздовжніх / поперечних | Підрізка на 2,4×2,4 м | Модуль, мм | Тайл текстури, мм |
|---|---|---|---|---|---|
| 01 | Ложкова ½ | 100% / 0% | 12 з 78 (15%) | 400×400 | 1600×1600 |
| 02 | Ложкова ⅓ | 100% / 0% | 16 з 80 (20%) | 400×600 | 1200×1200 |
| 03 | Сітка | 100% / 0% | 0 з 72 (0%) | 400×200 | 1600×1600 |
| 04 | Ялинка 90° | 50% / 50% | 12 з 78 (15%) | 800×800 | 1600×1600 |
| 05 | Ялинка 45° | 50% / 50% | 37 з 86 (43%) | 566×283 | 1697×1697 |
| 06 | Ложкова 45° | 100% / 0% | 41 з 90 (46%) | 283×283 | 1697×1697 |
| 07 | Плетінка | 50% / 50% | 0 з 72 (0%) | 800×800 | 1600×1600 |
| 08 | Т-плетінка | 33% / 67% | 0 з 72 (0%) | 800×600 | 2400×2400 |
| 09 | Поперечна смуга | 50% / 50% | 6 з 75 (8%) | 400×800 | 1600×1600 |
| 10 | Вітряк | 60% / 40% | 0 з 72 (0%) | 2000×2000 | 2000×2000 |

Усі схеми автоматично перевіряються на точне покриття (без щілин і накладань) — `tools/schemes.py`.

## Blender (5.0+)

1. Відкрийте `blender/plyta_schemes.blend` (папку `plyta_400x200/` тримайте цілою — текстури підключені відносними шляхами). Файл відкривається в режимі Material Preview.
2. Сфери стоять уздовж осі X через 2 м: куля 01 — X = 0, 02 — X = 2, … 10 — X = 18. Майданчик 4×4 м — у точці (0, −5).
3. Матеріали `Plyta_01_…` – `Plyta_10_…` позначені як Assets: Asset Browser → Current File → перетягніть на об'єкт.
4. Масштаб: у матеріалі 1 одиниця UV = 1 м (для плоских ділянок можна замінити вихід `UV` вузла Texture Coordinate на `Object`).
5. Рельєф швів: Cycles → Material → Settings → Displacement = *Displacement and Bump* + модифікатор Subdivision (Simple, 5–6 рівнів на рендер).

## Archicad

**Матеріал (3D/рендер):** Options → Element Attributes → Surfaces → New.
* Texture: `*_BaseColor.jpg`, розмір текстури — ширина × висота з колонки «Тайл текстури» (напр. 1600 × 1600 мм).
* Renderer (Redshift/CineRender): Normal/Bump → `*_Normal.jpg`, Displacement → `*_Displacement.png` (висота 10 мм), Roughness → `*_Roughness.jpg`.
* Призначте поверхню перекриттю/Mesh/Shell мощення; початок і напрям текстури задайте командою Align 3D Texture → Set Origin.

**2D-план:** File → Interoperability → Merge… → `dxf/<схема>.dxf` (одиниці — мм). Шари `PLYTA_*` стануть шарами Archicad. Щоб зробити штрихування: виділіть лінії одного модуля → Copy → Options → Element Attributes → Fills → New → Symbol Fill → Paste.

## Lumion 11

Lumion 11 підтримує колір, нормалі та карту висот (Displacement — з версії 10.3). Roughness і AO в Lumion 11 не потрібні: блиск задається повзунком, AO вже трохи «запечене» в колір.

| Слот матеріалу Standard | Файл з `textures/<схема>/` |
|---|---|
| Color Map (Texture) | `*_BaseColor.jpg` |
| Normal Map | `*_Normal.jpg` |
| Displacement Map | `*_Displacement8.jpg` |

### Спосіб А — масштаб з Archicad (рекомендовано)

1. В Archicad створіть для мощення окрему поверхню (напр. `PLYTA_04`) з текстурою `*_BaseColor.jpg` і розміром з колонки «Тайл текстури» (див. розділ Archicad) та призначте її верху перекриття/Mesh.
2. Передайте модель у Lumion як зазвичай (LiveSync, .dae, .fbx або .skp). Текстура прийде з правильним масштабом через UV.
3. У Lumion: Material → клік по мощенню → **Custom → Standard**. Color Map залиште тим самим файлом, **Map Scale — Imported** (значення 0), тоді розмір каменю береться з Archicad.
4. Normal Map → `*_Normal.jpg` (не натискайте «Create Normal Map from Color Map»). Якщо шви виглядають опуклими, а не заглибленими, натисніть **Flip Normal Map direction**.
5. Settings → Displacement Map → `*_Displacement8.jpg`, силу рельєфу почніть з малого значення: фаска плити лише ~5 мм.
6. Gloss ≈ 0,2–0,3, Reflectivity низька — бетонна бруківка матова.

### Спосіб Б — масштаб вручну в Lumion

Якщо модель прийшла без текстури, задайте Scale у матеріалі вручну й перевірте за розміром каменю: двері шириною 0,8 м ≈ 2 плити по довжині (400 мм) або 4 по ширині (200 мм); людина в Lumion ≈ 1,75 м ≈ 4,4 плити по довжині. Розмір одного повтору текстури — у колонці «Тайл текстури».

## Інші програми

* **Twinmotion / Enscape / D5:** створіть матеріал, підставте карти за назвами, розмір тайла — з `textures.json`.
* **3ds Max (DirectX), Unreal:** інвертуйте зелений канал нормалі (Flip Green / Y−).
* **SketchUp:** Materials → Create → `*_BaseColor.jpg`, розмір — з таблиці; решта карт — у V-Ray/Enscape.
